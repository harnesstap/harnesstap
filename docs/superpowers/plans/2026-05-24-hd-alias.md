# `hd` Alias Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish and support `hd` as a first-class alias for the `harnessdeck` CLI command.

**Architecture:** Keep one built entrypoint (`dist/index.js`) and expose it via two binary names in `package.json`. Inside `src/index.ts`, derive the invoked command name from `process.argv[1]` once, then reuse that value for help output, deprecation guidance, and other user-facing command suggestions. Extend the CLI test harness so integration tests can simulate either binary name.

**Tech Stack:** TypeScript, Commander, Bun, Vitest

  args: string[],
  options: { commandName?: string } = {},

  const commandName = options.commandName ?? "harnessdeck";
  // ...
  process.argv = ["node", commandName, ...args];

- [ ] **Step 3: Add a single source of truth for the invoked CLI name**

```ts
function getInvocationName(): "harnessdeck" | "hd" {
  const invoked = basename(process.argv[1] ?? "").trim();
  return invoked === "hd" ? "hd" : "harnessdeck";
}

const invocationName = getInvocationName();

function formatCommand(path: string): string {
  return `${invocationName} ${path}`.trim();
}
```

- [ ] **Step 4: Reuse the invocation name in help and guidance strings**
