# HarnessDeck VHS demos

These demos are generated from the checked-in tapes in `tapes/`.

## Prerequisites

- `bun`
- `vhs`
- `ffmpeg`
- `ttyd`

## Regenerate

```bash
bun run docs:vhs
bun run docs:vhs -- --scenario 01-existing-repo-adoption
```
