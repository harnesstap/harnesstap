# Manage deck records

Walkthrough for [Scenario 30](../../details/30-manage-deck-records.md).

## Commands

1. `harnessdeck deck list`
2. `harnessdeck deck import ./team-deck`
3. `harnessdeck deck show team-platform --format json`
4. `harnessdeck deck export team-platform --output ./team-deck-copy --with-layer-exports`
5. `harnessdeck deck doctor ./team-deck-copy`
6. `harnessdeck deck delete old-deck --force`
