## harnesstap v1.3.0 - October 11, 2026

### Added


  - Add Library list edit mode with a sticky add/delete FAB and bulk delete confirm.

  - Register local git marketplaces (path or file://) and optional extra tracked branches, with plugins deduped by identity across branches.

  - Show a healthy or error reachability mark on each marketplace in the Discover manage modal.

  - Omit Claude Code mod modules (in-process hooks.json + JS/TS) from non-Claude host plugin dual-write; keep portable pin files and warn.

  - Add a Discover control that copies a hit into the Library if needed, attaches it to the current profile, and applies that profile.

  - Add a Discover sidebar Not in my library filter that hides in-library hits when checked.

  - Scope a profile resource to a subset of harnesses. Default All is a sentinel. Apply writes only to scoped harnesses.

  - List apply removals in three groups on Desktop preview and View changes. Confirm before removing user-modified or unmanaged files. Result toast is Wrote N, removed M, kept K with View snapshot (DS-1/DS-6 copy).

  - Offer Also use on for a portable MCP that is only on some registered harnesses, with Not now. Accepting updates scope the same way as Use on and writes nothing until Apply.
