## harnesstap v1.3.2 - October 12, 2026

### Fixed


  - Exported, packed, and published Agent Plugins packages now declare the official `$schema` (`https://agent-plugins.org/schemas/1.0.0/plugin.schema.json`), so other Agent Plugins clients recognize them. Packages with the old HarnessTap identifier still import.

  - Exported and packed `mcp.json` now follows Agent Plugins 1.0.0: it declares `$schema` and an explicit `type` per server (`stdio`, or `streamable-http` for HTTP servers), so other Agent Plugins clients load the MCP servers. Settings the spec cannot hold are kept in `com.harnesstap/mcp.toml`.
