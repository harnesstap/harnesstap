## harnesstap v1.1.0 - September 03, 2026

### Added


  - Detect a newer published HarnessTap version and tell the user once (CLI notice, Desktop header badge with in-app GitHub installer update).

### Changed


  - Update Desktop profile edit chrome — resource inspect from composition rows, publish in the Profiles rail with a catalog-picker dialog, icon Remove profile, and a None/create default-environment dropdown.

### Fixed


  - Hide inherited host-plugin skills, agents, and commands from Desktop apply-preview stack and file changes when that plugin is already deployed.

  - Treat Cursor-native plugin MCP (including Slack) as present in apply-preview install gaps instead of a missing HarnessTap install.

  - Omit stale whole-file mcp.json snapshot MCP from Desktop apply-preview stack removals when those servers are gone from the live harness file, and show each MCP server’s live config in resource details.

  - Offer on-disk skills and extra MCP servers that are not in the selected profile as not-staged so they can be added, instead of only listing them as apply removals.

  - Keep a single open-in-editor control on the resource Path row and even out inspect detail-row spacing.

  - Merge Claude settings.json and subset skill snapshots on apply/preview instead of whole-file deletes, and list live modifications in Not staged with Plus overwrite and a diff icon.

  - Show a plus mark in Desktop Target preview install gaps for MCP servers that would be newly installed, and keep the warning mark when live MCP config differs from the expected install.

### Docs


  - Link the public README to HarnessTap Cloud docs at harnesstap.com/docs.
