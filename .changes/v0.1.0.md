## harnesstap v0.1.0 - August 26, 2026

### Features


  - Add Changie-based semver, CHANGELOG.md, and CI release workflows (tag-triggered npm publish and GitHub releases)

  - Add Tauri desktop app with Variant A persona control plane UI and embedded ht-agent sidecar

  - Add registry support for Antigravity, Amazon Q, Aider, Zed, Devin, Jules, Cody, and Grok Build

  - Promote Grok Build to a native serializer with MCP, permissions, hooks, agents, commands, and model config

  - Add compiled Bun sidecar agent with loopback health endpoint and session token file

  - Extend GlobalProfileStatus with depth/as_of, panel G/Y/R, harness plugin/MCP rows, and project drift via projectPath

  - Import Claude installed plugins as plugin_pin resources during home scan

  - Add plugin cut, dirty-head indicators, and version history pruning for shareable plugin versions

  - Desktop Resources view gains a filter sidebar (type, updated, namespace, origin); library list includes updated_at and origin_kind

  - Add marketplace browse/register and plugin search/add CLI for pinning host plugins.

  - Surface Claude settings.json permissions, env vars, and hooks in Not staged and File changes when unmanaged or partially managed

  - Resolve plugin apply as a dependency graph with version mediation and nearest-to-root resource precedence, record the resolved set in .harnesstap/lock.toml, and add --explain, --update, and `plugin why`

  - Unify plugin pins and nested plugin references into one plugin dependency type with provenance, surface origin in listings, gate edit/cut/publish/sync on it, and add `plugin fork`

  - Add ht resource directories list/add/remove/rescan to manage remembered library scan roots.

  - Add a desktop History drawer to list project apply snapshots and confirm-revert them through the agent.

  - Add desktop environments workspace and agent routes for list, status, show, create, edit, delete, and global use.

  - Import project scans, skill packages, and from-project plugins into the library from the desktop Resources panel

  - Show a read-only project config inspector in Settings, loaded from GET /v1/config with the same JSON as ht config show and validation errors from ht config validate.

  - Unregister a plugin marketplace from desktop Settings without leaving pinned plugins installed.

  - Add desktop Apply plugin drawer and POST /v1/apply for library plugin graphs without profile switch.

  - Add ht profile commands to adopt, commit, restore, remove, and diff live files.

  - Add ht open to open an allowed file or directory in the system editor.

  - Make profile switch treat Ctrl-C like desktop Cancel — abort before apply writes, ignore SIGINT while apply or restore is running.

  - Add profile stash apply (keep) on ht-agent and Apply (keep) beside Restore (drop) in the desktop stash browser.

  - Add `ht profile preview` to show apply preview (contents, files, untracked, recovery) without writing.

  - Extend `ht profile create` with `--compose`, `--from-home`, `--from-project`, and `--preview` so CLI profile creation matches the desktop library sources

  - Add a Settings Advanced check that pins last-applied resource winners as overrides when current resolution would pick a different plugin.

  - List and switch HarnessTap Cloud organizations from the desktop account drawer

  - Add a default-environment picker on desktop profile edit, wrapping plugin environment set and clear.

  - Add a desktop Plugins workspace for local library plugin list, composition, cut, delete, doctor, and fork.

  - Add desktop profile delete (demote, optional library plugin removal) via DELETE /v1/profiles/:name.

  - Add desktop plan/publish for profiles, publish catalog registration, and per-profile catalog allow lists via ht-agent.

  - Desktop resource detail pane can sync marketplace-linked definitions and delete library rows

  - Seed a default environment on agent boot and init so desktop always has one to list.

  - Add native DeepSeek Harness scan and apply for skills, MCP, hooks, presets, and dsh plugin installs

  - List plugin version history and restore a frozen cut onto the working head.

  - Detect Copilot CLI from ~/.copilot and import installed plugins as plugin pins on home scan

  - Add a Copilot CLI plugin provider that installs and updates via copilot plugin

  - Register Cursor plugin marketplaces via agent plugin marketplace add on apply and plugin add

  - Add an explicit desktop back control before workspace titles that returns to the previous screen and deactivates when history is empty.

  - Add a Sources workspace for marketplace and catalog discovery.

  - library plugins can check and update from marketplace, git, and catalog origins using git hashes.

  - Library desktop can check origin drift, badge outdated plugin packages, and run Update / Update all.

  - Resource delete can remove a library row only or also clean known on-disk locations, with a preview plan that surgically edits shared files and blocks modified or ambiguous paths

  - Allow drag-and-drop reorder of profiles in the desktop Global/Project rail (per-view localStorage).

### Added


  - Replace the Library "Create plugin" draft with a create-resource flow covering every resource type, with a type picker, single-page validated forms, and an optional add-to-current-profile-and-apply shortcut.

  - Add a CI desktop typecheck job so `apps/desktop` TypeScript regressions fail PR validation instead of surfacing at `desktop:dev` runtime.

  - HarnessTap Cloud publishes and serves Agent Plugins packages exclusively, on `/api/plugins` and a `package` download route. Requests carry a CLI and API version, and a CLI below the supported floor now fails with an upgrade instruction

  - Give apply-preview errors real recovery actions, including create-plugin, singleton pick-winner, and tag-as-profile

  - Refresh VHS walkthroughs and CLI docs for top-level `ht apply` and the plugin command surface

  - Group desktop target-preview file changes by resource, with expandable per-harness paths

  - Remove the always-on sidecar connected glyph from the desktop header; disconnect still uses the retry banner

  - Replace the Library namespace radio list with a searchable select field.
