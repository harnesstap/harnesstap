## harnesstap v1.2.0 - September 29, 2026

### Features


  - Pull marketplace plugin versions from the git source, pick one in a filterable combobox, and apply the selected version. Resource details header shows Pull/Sync and Delete only (no type label).

### Added


  - Emit anonymous CLI and Desktop PostHog events for install, Cloud connect, and plugin apply, with opt-out via HARNESSTAP_TELEMETRY=0.

  - Add a native Muse Code (Meta) harness (`muse-code`) with merge-safe user settings, `mcp_servers`, project hooks, and AGENTS.md / `.agents/skills` apply.

  - Ask for telemetry consent on first Desktop start, persist the choice in Settings, print a one-time CLI warning with opt-in/out instructions, and keep capture off until consent (env override still works).

  - Import GitHub plugin.json packages into the library from Desktop Create (header Import) and `ht plugin add`.

  - Desktop motion system with token-driven enter/exit recipes for dialogs, panels, menus, and popovers, plus Presence, Collapse, and Crossfade components, all disabled under prefers-reduced-motion.

  - Command palette (Ctrl/⌘K), destination shortcuts, and a keyboard cheat sheet in Desktop.

  - Desktop web-mode visual compare, axe, reduced-motion, and motion-trace checks (`bun run desktop:check`).

  - Add a native MiniMax Code harness (`minimax-code`) with merge-safe user MCP, project `.mcp.json`, AGENTS.md, and `.minimax/skills` apply.

  - Desktop Harnesses destination (⌘/Ctrl+4) with detect, add, remove, and make-main over `GET /v1/harness/inventory`; the Settings Harnesses tab is gone and the project harness override lives on Settings → Project. Export, Import, and Account moved into the header More menu.

  - Union configured harnesses (main + aliases) via `ht harness sync` and Desktop Harnesses Sync harnesses, with main-wins conflicts and shared skill path preference.

  - Scan Cursor host plugins and materialize Claude Code and Cursor plugin install trees during harness sync.

  - Scan and merge-apply Claude Code user-scope MCP from ~/.claude.json without dual-writing project .mcp.json or clobbering OAuth/session state.

  - Inventory Claude Code local-scope MCP from ~/.claude.json projects without promoting into .mcp.json or user mcpServers.

  - Show host plugin cache versions on Library plugin details and switch the installed version from a dropdown.

  - Treat Cursor's public marketplace (cursor-public at https://github.com/cursor/plugins) as a native git source so Pull clones it for Claude and other harnesses without a local Cursor install.

  - Materialize Cursor and Claude plugin skills into `.agents` during harness sync, with symlink/copy/clone modes and CLAUDE.md linking to canonical AGENTS.md.

  - Desktop Sync harnesses confirm modal previews per-harness change counts from a dry-run, with a loader until the preview finishes.

  - Harnesses inventory Plugins heading has Pull all, which fetches each listed plugin's latest source version, applies it when newer, and opens a Plugin updates report of what changed.

  - Desktop Harnesses inventory: open icon beside each harness section heading reveals that location on disk.

  - Write `.harnesstap` plugin-translation markers during harness sync and skip marked paths on home/project scan so translated plugin artifacts are not imported as standalone resources.

  - Add Desktop **Discard** / **Discard all** on profile **Not in profile** inventory rows to remove live harness copies (agent discard-resource APIs).
