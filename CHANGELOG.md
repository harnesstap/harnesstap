## harnesstap v1.0.0 - August 31, 2026

### Breaking Changes


  - Replace `.harnesstap/config.toml` and `.harnesstap/lock.toml` with `apm.yml` and `apm.lock.yaml` as the only project manifest and lockfile. HarnessTap-only fields are first-class top-level keys (`default_profile`, `environment`, `profiles`, `plugins`), not vendor extensions. `environment` is a mapping (`default` plus named environments) honored by config, use, apply, and lock replay.

  - Rename the `apm.yml` environment mapping from `environment` to `environments` so it matches plural `profiles` / `plugins`. `environments.default` is the active name; other keys are named environments with `values` / `secret_refs`. No fallback, migrate warning, or leftover `environment:` / `x-harnesstap` read. Lockfile bound-name field stays singular `environment`.

### Added


  - Add `ht pack` to emit an Agent Plugins 1.0 bundle from `apm.yml`, with lockfile `pack.bundle_files` integrity on apply of a local directory or zip.

  - Add pre-deploy Unicode scanning and lockfile SHA-256 verification on apply, path-traversal guards, and `ht audit`.

  - Resolve `dependencies.apm` git entries to an exact commit on apply, record them in `apm.lock.yaml`, and replay the lock unless `--update` is passed.

  - Compile local `.apm/` primitives into target harness directories on `ht apply`, honoring `targets`/`target` and `compilation` and recording deployed file hashes.

  - Add `ht install` as the project onboarding alias for apply-from-manifest (`ht apply` with no plugin selector).

  - Evaluate `apm-policy.yml` before apply writes, and load it from `ht audit --ci` (sources, primitives, transitive MCP, fail-closed `policy.hash`).

  - Add an opt-in executable trust gate (`ht approve` / `ht deny` / `ht policy explain`) that parks unapproved dependency hooks, bin, and self-defined MCP, records lock `exec_status`, and fails `ht audit --ci` with `required-executable-untrusted`.

  - Add `ht lock export` to serialize `apm.lock.yaml` into a CycloneDX 1.5 or SPDX 2.3 SBOM inventory (no re-resolve, unsigned).

  - Show pending executable approvals on Desktop after apply, switch, and Project Install; return parked/execStatuses/warnings from agent apply/switch; add in-app raw apm.yml edit with validate-before-save.

  - Add `ht compile` as a named apply-from-manifest entry, `ht targets` as the resolved-apply preview, and `--target`/`--all` APM tokens so declared `targets:` win over harness preference and folder detection.

  - Walk fetched APM packages' dependencies.apm on ht install / apply, pin each in apm.lock.yaml, and fail closed on cycles, missing packages, and hash mismatch.

  - Resolve MCP Registry v0.1 identities in dependencies.mcp on ht install, and add ht install --mcp / ht mcp search|list|show|install.

### Changed


  - Attach unsigned HarnessTap Desktop installers for macOS (Apple Silicon and Intel), Windows (x64 and arm64), and Linux AppImage, deb, and rpm (x64 and arm64, built on Ubuntu 22.04) to each GitHub release.

  - Align CLI and Desktop colors with the brand mark (teal success, amber warn, blue badge/accent).
